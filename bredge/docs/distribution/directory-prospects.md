# The Bredge — Directory Prospects (research)

> **Brief §9.** Additional legitimate free/freemium B2B / data / tech-consulting /
> agency / entity directories — **beyond** the six covered in
> `distribution/profiles/` (Crunchbase, GoodFirms, TechBehemoths, Clutch, The
> Manifest, DesignRush). 28 prospects below, each scored and prioritised.
>
> **Reality check (matches `seo-backlinks-distribution.md`):** a *submitted*
> directory is **not** an earned backlink — only a **verified live page** counts.
> Almost every directory link here is **nofollow**; that is fine. The goals are (1)
> **entity consistency** for the knowledge graph and AI answers, (2) **referral**
> traffic, (3) **credibility** — not PageRank. Add a profile to `sameAs`
> (`seo-entity.md`) only once it is live and accurate.
>
> **VERIFY** = confirm the platform's current free-tier/link terms before acting.
> **OWNER TO CONFIRM** = depends on a business fact not yet verified (location,
> partnership, US presence, fee tolerance).

## Scoring legend
Ratings are **H / M / L**. Columns:
- **Fit** — audience overlap with mid-market data/BI buyers (or AI/knowledge-graph consumers).
- **Entity** — value for the knowledge graph / `sameAs` / name consistency.
- **Referral** — realistic click-through traffic.
- **Link** — SEO link value (mostly nofollow → L, but still worth it for the three goals above).
- **Cost** — Free / Freemium / Cond (conditional/partner/fee).
- **Editorial** — review/verification barrier (H = real gatekeeping = higher quality).
- **Effort** — owner time to complete.
- **Risk** — reputational/SEO risk (want **L**).
- **Priority** — P1 do first · P2 soon · P3 optional/conditional.

## Why these survive the quality bar
Every survivor clears **all** of these tests:
1. **Real gatekeeping or a genuine entity database** — editorial review, verification, or a legitimate company database you can *claim and correct* — not an auto-approve link dump.
2. **Free or a free tier that does not require paying to rank** — paid *promotion* may exist, but a truthful listing is possible without it.
3. **Real B2B/tech/data audience, or a knowledge-graph/AI consumer** — the listing reaches buyers or improves entity understanding.
4. **Accurate representation** — the platform lets the entity be described as `The Bredge`, data engineering/analytics/BI, without forcing a misleading category.
5. **No manipulative requirement** — no reciprocal-link demand, no hidden links, no link injection.

Nofollow is **not** a disqualifier here — for a young brand, consistent entity data + referral + credibility outrank a marginal follow link, and it keeps the backlink profile clean.

## Excluded — and why (the quality bar in action)
- **Generic "free web directory / add-your-URL" farms** (e.g. 1abc-style, FreeWebSubmission-style, "SoMuch"-style link lists) — no editorial, mass auto-approval, toxic link neighbourhoods, zero referral. Pure spam footprint.
- **"Guaranteed Top-10 agencies" paid placements / pay-to-rank lists** — misleads buyers and Google; ranking bought, not earned. (This is also why the DesignRush/Clutch packs say *decline the paid upsell*.)
- **"Submit to 500 directories" gigs / automated mass-submission tools** — creates an unnatural link pattern Google devalues or penalises.
- **PBNs, link networks, link-exchange directories** — manipulative; manual-action risk.
- **Sponsored-post / article-injection sites without `rel="sponsored"`/nofollow** — violates search-engine guidelines.
- **Uncorrectable scraped-data aggregators** that resell your data and offer no claim/edit path — no control, no accuracy guarantee, negligible value. (Reputable claimable aggregators such as Owler are *included* precisely because you can claim and correct.)

## Suggested sequence (owner)
1. **P1 first:** LinkedIn, Google Business Profile (if location confirmed), Wikidata, GitHub org + OSS asset — these carry the entity.
2. **P2 next:** Bing Places, UpCity, Sortlist, Owler, Trustpilot (with genuine reviews), Modern Data Stack.
3. **P3 as capacity allows / when conditions are met:** partner directories once partnerships exist; local/consulting/product listings once location, fee tolerance and fit are confirmed.
