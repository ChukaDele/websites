# The Bredge — Backlink Prospects (brief §10)

Competitor / industry backlink-gap research done **without paid tools** (no Ahrefs,
Semrush, Majestic). Built from public search patterns: guest-post / "write for us"
programmes, contributor platforms, resource roundups, curated lists, practitioner
community blogs, consultancy directories, conference / event pages and technical
newsletters. Every target below was checked to be a **real, current, relevant**
property — no invented URLs. Where a specific submission page was not verified, the
route names the real base domain and the mechanism to use.

## Rules of engagement (white-hat only)
- Never: buy links · PBNs · mass auto-directories · comment/forum spam · reciprocal-link
  swaps at scale · thin AI pages · fake awards/stats/reviews.
- Every pitch is **value-first and vendor-neutral**: original insight, synthetic data,
  no product pitch. Map each pitch to one specific Bredge asset so the link has a reason.
- Canonical name everywhere: **The Bredge** (never "Bredge Data", "Bredge Analytics",
  "The Bridge"). Site: `thebredge.com`.
- A submitted directory is **not** an earned link. Count only a verified live page.

## How to run the backlink-gap search without paid tools
Public queries that surface where competitors and peers already earn links (run in an
incognito window):
- `"data engineering" "write for us"` · `"analytics engineering" "guest post"`
- `"business intelligence" intitle:"write for us"` · `"data consultancy" "contribute"`
- `data engineering "resources" (roundup OR "best of" OR "reading list")`
- `[competitor name] -site:[competitor domain]` (see who links to / mentions them)
- `"data engineering consultancy" (directory OR "top firms")`
- `intitle:"awesome" ("data engineering" OR "business intelligence")` (GitHub lists)
- `("call for speakers" OR "call for papers") (data OR analytics OR BI) 2026`

Difficulty = effort/selectivity to land (Low / Med / High). Priority = value × fit
(P1 highest). Assets referenced by slug live under `/insights/*` and `/resources/*`.

### Sequencing (do this order)
1. **P1, Low difficulty first:** DZone + HackerNoon (drafts ready) → live author links.
2. **Ship the OSS asset**, then Data Engineering Weekly + awesome-list PRs (gunnarmorling / pracdata).
3. **Operator angle:** Mostly Metrics + SeattleDataGuy (reconciliation / first-hire).
4. **Editorial guest posts:** Locally Optimistic → Towards Data Science / KDnuggets.
5. **Directories + events** run in parallel (owner-gated account creation).

Track every prospect through the schema in `docs/seo-backlinks-distribution.md`
(`priority | domain | type | audience | submission URL | status | owner | submitted | live URL | follow/nofollow | referral | leads | notes`).
Count a link only when `status=live` and a live URL exists.
